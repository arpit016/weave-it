# Session Capture: Prd - 2026-06-11

## Summary

Closed the remaining PRD product decisions for removing hidden local workflow routing state. The v1 behavior should make active-change selection branch-derived, make capture target selection explicit, remove the stored artifact-lane command surface, and leave existing local session files untouched while ignoring their old routing fields.

## Decisions Made

- Workspace mode uses the workspace root branch as the active-change authority for v1.
- If the workspace root branch and a registered sub-repo branch disagree, v1 keeps root-authority behavior; a future enhancement may ask which branch to switch.
- Non-git folders should stop supporting implicit active changes.
- `current_artifact` should be removed as persisted lane state.
- Bare `weave-capture` should require an explicit artifact target in v1.
- `weave artifact current` should be removed immediately rather than deprecated or repurposed.
- Old local session fields such as `current_change` and `current_artifact` should be ignored silently and left on disk untouched.
- Durable staleness remains in `status.yml`; this change does not redesign staleness.

## Options Considered

- Letting bare `weave-capture` infer a lane from recent skill invocation and conversation substance.
- Keeping `weave artifact current` with a compatibility warning.
- Cleaning up or warning about legacy local session fields during rollout.
- Adding an explicit non-git active-change selection model.

## Rejected Approaches

- Persisting artifact-lane state as `current_artifact`.
- Falling back to `current_change` when the branch does not identify a change.
- Deprecating `weave artifact current` instead of removing it now.
- Opportunistically editing old local session files as part of this change.
