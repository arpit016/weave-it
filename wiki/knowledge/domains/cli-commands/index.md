# CLI Commands

This domain documents the current user-facing behavior of Weave CLI commands.

## Features

- [Core Command Reference](features/core-command-reference/behavior.md): plain-English guide to `weave init`, `weave add`, and `weave workspace`, with their options, mode-aware behavior, and common setup use cases.
- [weave doctor](features/weave-doctor/behavior.md): read-only project health report and safe missing-scaffold repair command.
